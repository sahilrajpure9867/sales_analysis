# 📌 Project Overview

This project analyzes **5 years of historical regional sales data** to identify revenue trends, profitability, customer behavior, product performance, and regional opportunities.

The objective is to convert raw business data into actionable insights using **Python, SQL, Excel, and Power BI**.

---

Many organizations struggle to understand:

✅ Which products generate maximum revenue?

✅ Which regions perform best?

✅ Which sales channels are most profitable?

📌 Wholesale drives the highest sales volume

📌 Export channel achieves higher average margins
